An analyst, not a chatbot.

Atlas BI is a full-stack AI business intelligence agent for an Indian e-commerce retailer.

What it does

Atlas turns a messy e-commerce export into a clean SQLite warehouse, then lets a business user ask questions in plain English. Answers are grounded in real queries, charts are generated from the same data, and every numeric claim is validated before it reaches the screen.

  • Sales, customer and product analytics
  • Multi-step revenue-decline diagnosis
  • Indian payment, city-tier and state views
  • Festive-calendar context for September softness
  • Data-quality report and deterministic rebuild

Architecture

Raw CSVs→Cleaning pipeline
SQLite warehouse→Analytics service
Controlled tools→LLM / deterministic planner
Grounding check→Dashboard & chat

FastAPI · SQLite · vanilla JS · Chart.js · OpenAI-compatible tool calling.

Guardrails

  • Read-only SQL with an allow-list and a 2-second limit
  • Purpose-built tools for every core business question
  • Numeric grounding check on every answer
  • Deterministic fallback if the LLM is down or ungrounded
  • No secrets in the repository; keys live in .env

Honest limitations

  • The dataset is a deterministic synthetic snapshot, not real company data.
  • Revenue excludes shipping and taxes; profit and inventory are out of scope.
  • Forecasting, external benchmarks and competitor analysis are intentionally unsupported.
  • The demo is anchored to the latest warehouse date, not the wall clock.
